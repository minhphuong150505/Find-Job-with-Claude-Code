\section{Key Projects}
\project{META-CXR - Multimodal AI for Chest X-ray Report Generation}{Graduation thesis \textbullet{} Solo}{https://github.com/minhphuong150505/Meta-CXR}
\begin{itemize}
  \item Reproduced and extended a two-stage vision-language model (IEEE Access 2025) in PyTorch on MIMIC-CXR: two medical vision encoders (BioViL-T, PubMedCLIP) + Q-Former classify 14 abnormalities, then MedGemma-4B fine-tuned with QLoRA writes the report.
  \item Model optimization: partially unfreezing both encoders raised test macro-AUROC 0.744 $\rightarrow$ 0.764 on 3,269 held-out studies (paired bootstrap CI above 0, gains on 14/14 labels), with thresholds calibrated on validation only.
  \item Fixed an image-representation bug: restored each encoder's native patch grid and removed a constant component by per-image centering, cutting pairwise patch cosine similarity from 0.674 to $-0.014$ at only +0.6\% step time.
  \item Reproducible experiments: controlled A/B runs dropped components with no measurable gain (Grad-CAM explanation loss, deeper unfreezing); joining MS-CXR boxes by image ID exposed 166 boxes leaking into the test split; 1,012 pytest tests passed.
  \item LLM debugging: found the chat stop token was overridden, so 78\% of generated tokens came after the model had finished.
  \item Infrastructure: full training on one 16 GB GPU (fixed recurring kernel faults traced to unstable RAM settings); multi-GPU DDP smoke runs on 2$\times$ T4 with checkpoints on Google Cloud Storage.
\end{itemize}
\vspace{2pt}
\project{FPT Tri Thuc - Enterprise RAG Assistant}{Personal project \textbullet{} Solo}{https://github.com/minhphuong150505/milvus-rag-demo}
\begin{itemize}
  \item Python ingestion pipeline (PDF / web / text loaders, chunking, embedding, hash dedup) into Milvus 2.4, plus a Spring Boot RAG API for Vietnamese Q\&A over FPT corporate documents.
  \item Pulls 64 candidates from Milvus, re-ranks by cosine plus keyword / bigram coverage, cites sources and abstains when evidence is weak; shows each chunk's cosine score in the UI so retrieval quality can be audited.
  \item Token streaming over SSE with JSON fallback and per-upstream timeouts; 25 JUnit / Mockito tests and 9 Playwright E2E tests; runs on Docker Compose.
\end{itemize}
